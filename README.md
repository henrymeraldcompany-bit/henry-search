# Henry Search — starter projectThis is the first frontend step for a phone-friendly search engine project.## Files- `index.html` — page structure- `style.css` — responsive styling- `app.js` — search form and safe result rendering## Important statusThe frontend is ready, but live results are NOT connected yet. The page calls `/api/search?q=...`; a backend and a working search provider must be configured before real results will appear. This starter deliberately does not invent results or hardcode an unreliable public search instance.## Phone-friendly next steps1. Create a public GitHub repository named `henry-search`.2. Upload these three files to the repository's root folder.3. Enable GitHub Pages to preview the interface. GitHub Pages only hosts the frontend; it does not run a Node.js backend.4. In the next implementation step, add a backend (for example, Node.js) that provides `/api/search` and forwards searches to a permitted provider with JSON access enabled.## Expected API responseThe backend should return JSON like:{  "results": [    {      "title": "Example page title",      "url": "https://example.com/page",      "content": "A short description returned by the search provider."    }  ]}Do not put secret API keys in frontend JavaScript. Respect search provider terms, rate limits, website policies, and privacy.
